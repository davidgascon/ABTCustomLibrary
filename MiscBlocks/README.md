# ABTCustomLibrary

Custom library for ABT

Nathan provided several blocks for us to use, which can be found in the MMFS_Library2.s1cx file. Download this file, then import into ABT to start using his blocks.

To import custom blocks to library
1. Download the blocks you want. Save them somewhere easy to reference.
2. In ABT, open TIA. Open the library window.
3. Right click on Custom Library, then select the blocks you downloaded. 

To upload a new revision of the block, upload a new file with the same name as the old block. This will automatically create a new revision in Github.
