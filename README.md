# ABTCustomLibrary

Custom library for ABT

Nathan provided several blocks for us to use, which can be found in the MMFS_Library2.s1cx file. Download this file, then import into ABT to start using his blocks.

To import custom blocks to library
1. Download the blocks you want. Save them somewhere easy to reference.
2. In ABT, open TIA. Open the library window.
3. Right click on Custom Library, then select the blocks you downloaded.


To create a new issue, click Issues, then create a new one. Reference the name of the block in the title, then a brief summary of the issue.

Below is the workflow to edit a block.
1. Create a new branch. Name it something that makes sense, like "Reworking pump control block". This creates a new branch where you can safely test new blocks while preserving the primary branch.
2. Reupload the revised block using the same name as the old one. This preserves the version control.
3. Create a pull request. Once tested and confirmed, the pull request will be approved and brought into the main branch.
